# Module 25: NumPy Arrays

Install first: `pip install -r requirements.txt`. Run one lesson with `python lesson_01_introduction_environment.py`.
Check all of them with `pytest -q`: every lesson ends with an `# EXPECTED OUTPUT` block that the test compares.

| lesson_06 | Arrays from numerical ranges |
| lesson_07 | Iterating over arrays |
| lesson_08 | Reshaping arrays |

| lesson_10 | Splitting |
