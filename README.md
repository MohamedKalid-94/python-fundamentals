## How to run

```bash
git clone https://https://github.com/MohamedKalid-94/python-fundamentals
cd python-fundamentals/01_python_basics
python 02_variables.py
```

Requires Python 3.10 or newer. No third-party packages are needed.

## How each module is organised

- Numbered `.py` files, one concept each, with expected output in comments
- `exercises.py` with practice problems
- A module `README.md` listing the topics covered
