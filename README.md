# Module 01: Python Basics

## Topics covered

| File | Topic |
|------|-------|
| 01_home_and_syntax.py | How Python runs, syntax, indentation, keywords |
| 02_variables.py | Names vs objects, naming rules, dynamic typing |
| 03_private_variables.py | `_x` and `__x` conventions, name mangling |
| 04_data_types.py | Built-in types, mutable vs immutable |
| 05_type_casting.py | Explicit and implicit conversion |
| 06_unicode.py | `str` vs `bytes`, UTF-8 |
| 07_literals.py | Number, string and collection literals |
| 08_comments.py | Comments and docstrings |
| 09_user_input.py | `input()` and `print()` options |
| 10_numbers.py | int, float, complex, math helpers |
| 11_booleans.py | Truthiness, `and`/`or` behaviour |
| 12_floating_points.py | Precision, `isclose`, `Decimal` |
| exercises.py | Practice problems |

## Run

```bash
python 01_home_and_syntax.py
```
