# Module 22: FastAPI Basics

Install first: `pip install -r requirements.txt`. Run the tests with `pytest -q`.
Run an app with `fastapi dev app_01_hello_world.py` and open http://127.0.0.1:8000/docs.

| Files | Topic |
|-------|-------|
| app_01 / test_01 | Introduction, Hello World |
| app_02 / test_02 | OpenAPI, Uvicorn |
| app_03 / test_03 | Type hints, IDE support |
| app_04 / test_04 | REST architecture, status codes |
| app_05 / test_05 | Path parameters |
| app_06 / test_06 | Query parameters |
| app_07 / test_07 | Parameter validation |
| models_08 / test_08 | Pydantic |
| app_09 / test_09 | Request body |
| app_10 / test_10 | Errors, status codes, settings |
| exercises.py | Practice problems |
