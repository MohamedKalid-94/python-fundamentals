# Module 23: FastAPI Requests and Responses

Install first: `pip install -r requirements.txt`. Run the tests with `pytest -q`.
Run an app with `fastapi dev app_01_templates.py` and open http://127.0.0.1:8000/docs.

| Files | Topic |
|-------|-------|
| app_01 / test_01 | Templates (Jinja2) |
| app_02 / test_02 | Static files |
| app_03 / test_03 | HTML form templates, form data |
| app_04 / test_04 | File uploads |
| app_05 / test_05 | Cookie and header parameters |
| app_06 / test_06 | Response model |
| app_07 / test_07 | Nested models |
| app_08 / test_08 | Dependencies |
| app_09 / test_09 | CORS |
| app_10 / test_10 | Async endpoints, background tasks |
